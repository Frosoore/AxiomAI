# Kernel: Modding & Extension System

The `axiom.kernel` subpackage implements the modular micro-kernel architecture:
manifest parsing, DAG topological resolution, registry of hooks and slots,
transactional step execution bus, dynamic patcher, sandboxed testing, scaffolding,
live hot-reloading, LLM mod generation, and remote store distribution.
