# DOC — QoL Creator Studio

## Objectif
Améliorer l'ergonomie et la réactivité du Creator Studio :
- Rendre la suppression cohérente sur les tables (qu'une colonne, plusieurs cellules ou une ligne soient sélectionnées, la suppression via la touche Suppr/Del, le bouton Défaire/Supprimer ou le menu contextuel doit supprimer les entités/lignes correspondantes au lieu de simplement vider le texte des cellules sélectionnées).
- Menu contextuel d'ajout et suppression accessible au clic droit.
- Clic direct sur les widgets de cellules sélectionnant automatiquement la ligne.
